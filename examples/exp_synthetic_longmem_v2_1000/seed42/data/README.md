# 1000 步合成知识追踪数据

- `train.csv`：48 名学生；`valid.csv`：12 名；`test.csv`：24 名。每名学生一行，序列长度均为 1000。
- 字段：`uid, role, fold, concepts, questions, responses`。序列字段用逗号分隔；知识点 ID 为 0–47，回答为 0/1。`questions` 暂与 `concepts` 相同；本实验模型显式使用 `n_pid=0`。
- `fold`：训练为 1，验证为 0，测试为 -1。学生 ID 不重叠，学生 ID 和 role 不输入模型。
- 第 0–199 步练习知识点 0–31；200–799 步练习 32–47；800–999 步回访 0–31。每段通过随机排列循环安排知识点，各学生的顺序不同。
- 每名学生、每个知识点独立初始化二值掌握状态。未掌握知识点每次练习后以 0.015 概率转为掌握。回答为带能力/难度偏移的 Bernoulli 采样，非确定性复制历史回答。
- `diagnostic_labels.json` 的隐状态生成概率和首次回访标记只用于分析，不输入模型、不用于训练标签之外的额外监督。
- 计分：按 200 步切块，每块第一个位置不计分；其他有效位置计分。所有比较模型使用完全相同的 mask。
- `manifest.json` 保存数据种子、生成机制与 CSV SHA256。数据种子固定为 20261025，三个模型种子使用同一数据集。

生成和实验入口：仓库根目录的 `examples/experiment_long_mem_topk_akt_synthetic.py`。训练采用完整学生轨迹顺序 replay，每次提交一个完成块的记忆；每个 epoch 和数据划分重新建立缓存。
